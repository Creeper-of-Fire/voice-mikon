# 术语表(热词)模板 —— 复制到 data/hotwords.txt 后生效
#
# 一行一词。# 开头是注释,空行忽略。
# 程序启动时自动读取 data/hotwords.txt,与 config.json 里的 hotwords 合并。
#
# 作用:官方叫 Context Biasing —— 模型在音频模糊时会优先选这些词。
# 实测:专有名词 "Qwen3-ASR" 无热词时听成 "Queen三ASR",
#       加上术语表后完全纠正。
#
# 怎么维护:
#   1. python scripts/build_hotwords.py    # 从聊天记录提取候选(带频次)
#   2. 人工挑一遍 —— 留下真会被口述的专有名词,删掉代码标识符和普通词
#   3. 存到 data/hotwords.txt
#
# 注意:
#   - 词条越多偏置越强,但也越容易误触发(把没说的话写出来)。
#     建议控制在 60~120 条,宁缺毋滥。
#   - 优先收录「读音和写法差别大」的词(Queen/Qwen、ASR/三ASR),
#     拼写本来就对得上的词(如 API、PDF)帮助不大。
